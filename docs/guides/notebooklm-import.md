# NotebookLM(제미나이 노트북) 자료 가져오기

자기야, 노트북LM에 정리해둔 양자역학 자료들 2nd BRAIN으로 옮기는 법 정리해봤어! 결론부터 말하면 — **공식으로 딱 되는 API는 없어.** 구글이 로그인 없이는 절대 안 열어주더라고 (공유 링크도 마찬가지야, 브라우저에서 구글 계정으로 로그인해야만 보여). 그래서 방법을 두 가지로 나눴어: 손으로 하는 확실한 방법, 그리고 귀찮으면 대신 돌려주는 자동화 스크립트. 뭐가 됐든 일단 `바탕화면/2ndBRAIN/<책이름>/` 폴더에 파일만 떨어뜨리면 그 다음은 brain-sync가 알아서 업로드해주니까 걱정 마.

## 1. 빠른 방법 (공식, 확실함)

1. 노트북LM(Studio)에서 저장해둔 노트나 리포트 옆의 **⋮ 메뉴 → "Google Docs로 내보내기"** 를 눌러줘.
2. 방금 만들어진 Google Docs 문서를 열어서 **다운로드 → Markdown(.md) 또는 일반 텍스트(.txt)** 로 저장해.
3. 다운로드된 파일을 `바탕화면/2ndBRAIN/양자역학/` (또는 해당 책 폴더)에 넣어줘.
4. 원본 PDF가 있다면 — 노트북LM에 업로드된 PDF 자체는 다시 못 꺼내니까 — 원래 갖고 있던 곳에서 같은 폴더로 복사해줘.
5. 끝! brain-sync가 켜져 있으면 몇 초 안에 자동으로 업로드돼.

이 방법은 항목마다 손으로 눌러야 하는 게 좀 번거롭지만, 구글이 뭘 바꾸든 절대 안 깨지는 유일한 방법이야. 새 자료 몇 개 정도면 이걸로 충분해.

## 2. 자동 방법 (비공식, 선택사항)

노트북에 소스랑 노트가 많아서 하나씩 내보내기 귀찮다면, `notebooklm-py`라는 커뮤니티 오픈소스 클라이언트를 써서 자동으로 긁어올 수 있어. 다만 이건 구글 공식 API가 아니라 브라우저 쿠키로 로그인 흉내를 내는 방식이라 **구글이 내부 구조를 바꾸면 예고 없이 깨질 수 있어** — 그럴 땐 그냥 1번 방법으로 돌아가면 돼.

### 설치

```bash
pip install ".[notebooklm]"
```

### 로그인 (한 번만)

```bash
notebooklm login
```

브라우저가 뜨면 구글 계정으로 로그인해줘. **여기서 중요한 거 — 본계정 말고 전용 구글 계정을 하나 파서 쓰는 걸 추천해.** 로그인 쿠키가 컴퓨터에 파일로 저장되는 방식이라(`~/.notebooklm/`), 혹시 모를 유출에 대비해서 본계정이랑 분리해두는 게 안전해. 저장된 쿠키 파일도 남한테 넘기거나 깃허브에 올리면 절대 안 돼!

### 가져오기

먼저 `--dry-run`으로 뭐가 들어올지 확인부터 해봐:

```bash
brain-nblm --notebook https://notebook.google.com/notebook/fd7a7958-36ea-4dfb-847d-20b96734d58a --book 양자역학 --dry-run
```

목록이 마음에 들면 `--dry-run`을 빼고 진짜로 저장해:

```bash
brain-nblm --notebook fd7a7958-36ea-4dfb-847d-20b96734d58a --book 양자역학
```

`--notebook`엔 URL을 통째로 넣어도 되고 UUID만 넣어도 돼(둘 다 알아서 인식해). 소스랑 노트가 `양자역학` 폴더에 `nblm-source-*.md`, `nblm-note-*.md` 파일로 떨어지고, brain-sync가 나머지를 처리해줘. 이미 가져온 내용은 다시 실행해도 중복으로 안 쌓이니까 주기적으로 그냥 다시 돌려도 괜찮아.

로그인이 만료됐거나 notebooklm-py가 안 깔려있으면 친절하게 안내 메시지를 띄우고 종료할 거야 — 그럴 땐 `notebooklm login`부터 다시 해줘.

## 3. 한계, 미리 알아두면 좋은 것들

- **공유 링크만으로는 클레어(나)도 접근 못 해.** "링크가 있는 모든 사용자"로 공개해둔 노트북이라도 브라우저에서 구글 로그인이 필요해서, 서버 쪽에서 그냥 긁어오는 건 불가능해.
- **업로드된 PDF 원본은 노트북LM에서 다시 못 꺼내.** 요약이나 노트는 내보낼 수 있어도, 처음에 넣었던 PDF 파일 자체는 원래 있던 곳에서 따로 챙겨와야 해.
- 자동 방법(`notebooklm-py`)은 비공식이라 구글이 내부 구조를 바꾸면 조용히 멈출 수 있어. 그럴 땐 당황하지 말고 1번 방법으로!
