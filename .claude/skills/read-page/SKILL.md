# /read-page — 사진 속 글자와 표시 읽기

무료 모델은 옅은 펜 줄을 놓칠 수 있어서, 텔레그램 사진은 기본으로 Clair가 읽어요(`OCR_MODE=clair`).
CLI는 `.venv/Scripts/python -m sync.learn_cli`(아래 `LEARN`)로 실행해요.

## 1. 대기열 보기
```
LEARN ocr list
```
없으면 "읽어 줄 사진이 없어요"라고 말하고 끝내요.

## 2. 한 장씩 읽기
각 id마다:
1. `LEARN ocr get <id> --out <스크래치패드 폴더>` — 그림 파일과 `<id>.txt`(뼈대)가 생겨요.
2. **Read 도구로 그림 파일을 열어요.** 글자뿐 아니라 여백, 줄 사이, 옅은 연필·펜 선까지 꼼꼼히 봐요.
3. `<id>.txt`를 아래 형식으로 채워요(안내 주석 줄은 지워요).
4. `LEARN ocr submit <id> <id>.txt`

## 3. 쓰는 형식 (정확히 이 모양)
```
<쪽 글자를 그대로. 문단은 유지. 독자가 표시한 구절은 본문 안에서 ==...== 로 감싸요>

## 표시 목록
- [밑줄] "..."        펜·연필 밑줄
- [형광펜] "..."
- [별표] "..."        여백의 별(*) — 옆에 있는 구절
- [괄호] "..."        여백의 괄호나 세로줄
- [동그라미] "..."
- [체크] "..."
- [기타: 설명] "..."
## 독자 메모
- 여백의 손글씨를 그대로 (옆에 있는 구절이 분명하면 함께)
## 쪽수
숫자 또는 모름
```
규칙:
- 없는 표시를 지어내지 않아요. 표시가 하나도 없으면 `## 표시 목록` 아래에 `- 없음`.
- 인쇄된 굵은 글씨·기울임은 독자 표시가 아니에요. 구분해요.
- 옅은 펜 선도 표시예요.
- 여러 줄에 걸친 표시는 구절 전체를 한 항목으로 인용해요.
- 표시된 구절은 항상 본문 안에서도 `==...==` 로 감싸요(밑줄 세는 기능이 이걸 봐요). 목록과 본문의 글자가 같아야 해요.
- 요약·번역 금지. 원래 언어 그대로(한국어·영어 섞여도 그대로).
- 손글씨 메모가 없으면 `## 독자 메모` 아래에 `- 없음`.

## 4. 많을 때
대기가 6장 이상이면 심부름꾼(sonnet)에게 나눠요. **한 명에게 그림 최대 5장**, 한 메시지에 병렬로 불러요.
지시에는 이 문서의 3번 형식과 규칙을 그대로 붙이고, "`ocr get`으로 받아 Read로 보고 `ocr submit`까지" 맡겨요.

## 5. CR에게 보고
짧게: 몇 장을 읽었는지 · 표시 총 몇 군데(밑줄·별표 등 종류별) · 어느 책(들). 제출하면 텔레그램에도 자동으로 알림이 가요.
