# /learn — 한 문장으로 배우기

CR의 한 문장을 서버의 학습 퀘스트로 보내고, 끝날 때까지 지켜보고, 결과를 보고해요.
**되묻지 않아요.** 기본은 초등 눈높이 · 7일이고, 문장에 일수나 레벨이 있을 때만 `--days`, `--level`로 넣어요.

CLI는 `.venv/Scripts/python -m sync.learn_cli`로 실행해요(아래에서는 `LEARN`이라고 줄여 써요).
주소와 토큰은 CLI가 프로젝트 루트의 `.env`(`BRAIN_URL`, `BRAIN_TOKEN`)에서 직접 읽어요. 프로젝트 루트에서 바로 실행하면 되고 따로 설정할 게 없어요.

## 1. 시작
```
LEARN start "<CR의 문장 그대로>" [--days N] [--level 초등|일반|전문]
```
퀘스트 이름(slug)과 주소가 나오고, 이어서 자동으로 지켜봐요. 시작 시각을 기억해 둬요(걸린 시간 보고용).

## 2. 지켜보기
`start`가 지켜보다 끊겼으면 `LEARN watch <slug>`로 이어요. 단계가 바뀔 때마다 한 줄씩 나와요.
종료 코드: 완료 0 · 실패 1 · 생각 담당 필요 3.

## 3. 종료 코드 3 — 생각 담당 (서버가 모델을 못 구해 과제를 맡긴 상태)
1. 스크래치패드에 폴더를 잡고 과제를 받아요: `LEARN tasks <slug> --out <폴더>`
2. 폴더의 `*.prompt.md`마다 심부름꾼을 하나씩 불러요. **한 메시지에 병렬로 한꺼번에** 불러요.
   - 모델: `plan`, `teach`, `bridge` 과제는 **opus**, `classify` 과제는 **sonnet**
   - 지시: `.prompt.md` 내용을 그대로 주고 "스키마를 만족하는 **JSON 객체 하나만** 돌려줘, 설명 금지"라고 해요.
3. 돌아온 JSON을 과제마다 파일(`<task_id>.out.json`)로 저장해요. 코드펜스나 설명이 섞였으면 JSON만 남겨요.
4. 하나씩 제출해요: `LEARN submit <slug> <task_id> <파일>`
   서버가 400과 함께 이유를 알려 주면(스키마 위반) 그 이유를 심부름꾼에게 보여 주고 고쳐서 다시 제출해요.
5. 다시 `LEARN watch <slug>`. 또 3이 나오면 반복해요.

세션이 끊겨도 괜찮아요. 서버가 대기 중인 과제를 30분마다 스스로 다시 시도해서,
모델이 쓸 수 있게 되면 퀘스트는 알아서 끝나요.

## 4. 완료(종료 코드 0) — 이렇게 보고해요
보고 내용은 `LEARN watch`가 끝날 때 출력하는 내용(또는 `LEARN status <slug>`)에 다 들어 있어요. 직접 HTTP를 부르지 말고 그 출력을 CR에게 한국어로, 쉬운 말로 옮겨요. 더 필요하면 `LEARN status <slug> --json`:
- 지도 링크 (전체 주소)
- 목표 한 줄
- Day 1 핵심 한 줄
- 예전 지식과 이어진 다리 3개 (없으면 "아직 없음")
- 새로 시도한 출처
- 비용 추정 (`cost_estimate`)
- 걸린 시간

## 5. 실패(종료 코드 1)
사유를 그대로 알려 주고 `LEARN resume <slug>`로 다시 시작해요. 같은 이유로 또 실패하면
이유와 함께 CR에게 어떻게 할지 물어요.
