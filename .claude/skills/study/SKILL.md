# /study — 공부 모드 (CR 결정 2026-10-25)

CR이 주말이나 틈틈이 혼자 공부하면서 Clair에게도 "주입"하는 시간이에요.
**목적 두 가지:** (1) CR이 초등학생도 이해할 만큼 쉽게 이해하기 (2) Clair의 두뇌에 차곡차곡 쌓고 예전 지식과 점-점(dot to dot)으로 잇기.

## 켜고 끄기
- "공부 모드"라는 말이 오면 바로 켜요. 되묻지 않아요. 세션이 끝나거나 "공부 모드 끝"이 올 때까지 유지해요.
- 켜질 때 한 줄만: "공부 모드 켰어요. 붙여 넣으면 바로 풀어 드릴게요."

## 길이 규칙 (CR 2026-10-25: "짧게 질문하면 너도 짧고 핵심만")
목표는 언제나 **CR의 완전한 이해**예요. 길이는 들어온 글에 맞춰요.
- **한두 문장·단어 하나** → 짧게. 한 줄 요약 + 핵심 3~5줄 + 정말 어려운 단어만 1~3개 + 연결 한 줄. 비유는 한 줄로, 정직 상자는 꼭 필요할 때 한 줄.
- **문단 하나** → 아래 전체 양식. 단어는 어려운 것 전부.
- **여러 문단·기사 전체·질문 여러 개** → 전체 양식 + 질문마다 소제목.
답이 길어질수록 CR이 안 읽어요. 짧아도 빠진 게 없으면 그게 스마트한 답이에요.

## 붙여넣은 글마다 이렇게 답해요 (순서 고정)
1. **한 줄 요약** — 이 문단이 하는 말 한 문장.
2. **쉬운 풀이** — 초등 눈높이. 짧은 문장, 비유 하나(동네 가게·운동장·도서관처럼 몸으로 아는 것), 숫자는 꼭 필요한 것만. 내 첫 시도보다 **훨씬 더** 쉽게.
3. **어려운 단어 풀이** — 문단 속 어려운 단어·영어·줄임말·회사 이름을 **빠짐없이** 하나씩. 단어마다 한두 문장, 예시 하나. (CR 지시: "문단에 나오는 어려운 단어들도 따로 쉽게 이해시켜")
4. **예전 지식과 이어진 점** — 두뇌에 이미 있는 책·퀘스트(양자역학·창세기·손자병법·인간관계론·THE MIND·장수마을 등)와 닿는 점 1~3개. 억지로 잇지 않아요. 없으면 "아직 없음".
5. **정직 상자**(필요할 때만) — 사실(확립됨)과 전망·주장(추측)을 구분해요.
6. 마지막에 **궁금증 질문 하나**(선택) — CR이 더 파고들 수 있게.

단어 하나만 오면 3번만, 링크가 오면 먼저 본문을 가져와서(WebFetch) 1~4번.

## 두뇌에 저장하기 (글마다, 답을 보낸 뒤 바로)
1. 스크래치패드 `study/` 폴더에 `<YYYY-MM-DD>-<주제-짧게>.md`를 써요. 구성: 제목 · 메타(날짜·출처·주제·#태그) · **원문 그대로** · 한 줄 요약 · 쉬운 풀이 · 어려운 단어 풀이 · 연결 후보 · 정직 상자.
2. 저장 스크립트를 돌려요 (주소·토큰은 `.env`에서 읽어요. 토큰을 채팅에 적지 않아요):
   ```
   PYTHONIOENCODING=utf-8 .venv/Scripts/python -X utf8 .claude/skills/study/study_save.py "<파일>"
   ```
   하는 일: `POST /upload`(book=공부모드) → `POST /catalog/learn?book=공부모드`(분류, Gemini 무료) → `POST /graph/rebridge?limit=20`(예전 지식과 다리 놓기) → 새로 생긴 개념·다리를 출력.
3. 출력된 다리(bridge)가 있으면 CR에게 한 줄로 알려요: "두뇌에 저장했고, ○○(예전 책)과 이어졌어요."
4. 분류가 503(생각 담당 없음)이면 저장만 되고 분류는 미뤄져요. 그대로 두면 다음 `catalog/learn` 때 처리돼요. CR에게 "분류는 나중에"라고만 말해요. 유료 API는 켜지 않아요.

## 세션을 끝낼 때
- 오늘 공부한 글 목록 + 새 개념 수 + 새 다리 수를 짧게 보고해요.
- NEXT.md 맨 위에 한 줄: 날짜 · 주제들 · 미뤄진 분류 여부.
- 공부한 내용은 볼륨 `books/공부모드/raw/`에 영구 보관돼요. 두뇌 그래프(`/site/brain/index.html`)와 Obsidian 내보내기(`/vault.zip`)에 자동으로 들어가요.
